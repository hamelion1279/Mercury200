# ESPHome: Zigbee-счётчик воды (ESP32-H2 Super Mini)

Прошивка `watermet-zigbee.yaml` для узла учёта воды:

- два импульсных входа (счетчики Бетар ХВС/ГВС, геркон, «сухой контакт»);
- контроль напряжения и заряда 18650 через делитель 1:1 на GPIO1;
- транспорт — **Zigbee 3.0** (родной компонент ESPHome), режим end-device;
- зарядка — модуль HW-107 (TP4056 + защита), питание платы от его OUT.

## Распиновка (ESP32-H2 Super Mini)

| Пин платы | Назначение в прошивке | Комментарий |
|---|---|---|
| GPIO14 | Импульсы ХВС | INPUT_PULLUP + инверсия; на H2 это XTAL_32K_N, но кварц на плате не распаян |
| GPIO12 | Импульсы ГВС | **Не GPIO13** — тот на Super Mini занят onboard-синим LED |
| GPIO1  | АЦП батареи (делитель 1:1) | 4.20 В батареи → 2.10 В на пине, `attenuation: 12db` обязателен |
| GPIO9  | Кнопка BOOT | strapping-пин, предупреждение ESPHome — норма |
| GPIO8  | — не использовать | onboard WS2812 |
| GPIO13 | — не использовать как вход | onboard синий LED (опционально: `status_led`) |

## Управление кнопкой BOOT

| Удержание | Действие |
|---|---|
| 5–15 с | `zigbee.factory_reset` — сброс сети, перепривязка к координатору |
| 20–40 с | обнуление накопительных счётчиков ХВС и ГВС |

## Важные ограничения (прочитать до сборки)

1. **Роутер от батареи нельзя.** `zigbee: router: false`. Роутер не спит никогда;
   если устройство будет постоянно запитано от USB/БП — верните `router: true`
   и `power_source: DC_SOURCE`.
2. **Спящего режима Zigbee на ESP32 в ESPHome нет** (`sleepy` реализован только
   для nRF52). End-device тоже держит радио включённым, поэтому автономность —
   дни/недели на 18650, а не месяцы. Оценочная цифра, токи не измерялись.
3. **По Zigbee наружу уходят только `sensor` и `binary_sensor`** (кластеры
   analog_input / binary_input). `button`, `switch`, `number` на ESP32 не
   публикуются, а `api`/`ota`/`mqtt` на H2 не поднять без Wi-Fi. Поэтому
   виртуальные кнопки из Home Assistant недоступны — все действия продублированы
   удержанием BOOT.
4. **Имена сущностей в Zigbee — только латиницей**: описание эндпоинта
   собирается через `name.encode("ascii", "ignore")`, кириллица превращается
   в пустую строку. Русские подписи давайте сущностям уже в Z2M/HA.
5. **`total:` не пишется во flash** — это счётчик сессии ESPHome. Долгая
   история живёт в long-term statistics Home Assistant; после полного сброса
   «накопленный м³» начинается заново (сбрасывается и удержанием BOOT 20–40 с).
6. **1 импульс = 10 л** (`multiply: 0.01`) — типовое для Бетар Ду15; сверьте с
   паспортом своих счётчиков и поправьте `litres_per_m3_pulse`.

## Калибровка АЦП

После первой прошивки сравните «Battery Voltage» с мультиметром на батарее.
Если расходится — замените `multiply: 2.0` на `calibrate_linear` по двум точкам
(пример закомментирован в yaml).

## Сборка и прошивка

Железо — ESP32-H2 Super Mini; в `esp32: board:` указан `esp32-h2-devkitm-1`,
потому что PlatformIO не знает board id «esp32-h2-super-mini» (тот же SoC,
та же flash 4 МБ, GPIO совпадают).

```bash
esphome run esphome/watermet-zigbee.yaml   # сборка + прошивка по USB
```

Плата шьётся через родной USB-Serial-JTAG (драйверы не нужны). Если порта нет:
удерживайте BOOT при подключении USB.

Статус проверки в песочнице Arena: `esphome config` — valid;
`esphome compile --only-generate` — main.cpp сгенерирован и сверен (endpoints,
attenuation, use_pcnt). Полная сборка бинарника там невозможна: CDN PlatformIO
(`release-assets.githubusercontent.com`, `dl.registry.platformio.org`) закрыты
сетевым фильтром — собирайте на своей машине.

## Схема измерения напряжения батареи

Файлы: `battery-divider.svg` / `battery-divider.png` (одно и то же,
вектор и растр).

```
B+ (3,0-4,2 В) ---[R1 100k]---+--- GPIO1 (ADC1_CH0)
                               |
                             [R2 100k]      C1 100nF
                               |              |
GND ---------------------------+--------------+---- GND ESP32
```

- R1 = R2 = 100 kΩ (±1 %, любые 0805/выводные) — коэффициент 1/2.
- C1 = 100 nF керамика — сглаживает шум и питает семплирующий конденсатор
  АЦП при высоком импедансе делителя; паковать ближе к пину GPIO1.
- Ток делителя ≈ 21 мкА при 4,2 В — пренебрежимо на фоне радиосвязи.
- Точки подключения: верх R1 — к B+ батареи (пада B+ на HW-107 или на
  защите), узел R1/R2/C1 — на GPIO1 Super Mini, низ R2 и C1 — на общий GND.
- 4,20 В батареи => 2,10 В на пине: вписывается в диапазон `attenuation:
  12db`; в прошивке это компенсируется `multiply: 2.0`.
